## 沉淀到运行时的写法

1. **自然分段。** 新闻、背景、分析、产品不再各自挤成一个大段；按独立信息和关系转向分段，不拆句凑数。连续自然段为默认，不机械增加小标题或编号。
2. **分析展开。** 从材料中的具体变化出发，解释影响需求、履约、经营、现金流或估值的环节，再说明对主线的含义。分析可以跨段推进，避免仅释义指标或反复说“值得观察”。推演保留必要条件，不能编造新的事实。
3. **实质产品推介。** 除名称和代码，解释跟踪指数的覆盖、选择特点、策略或有依据的参与渠道为何与当前主题有关。可前后呼应，每次提及增加信息；不固定只在最后留一句产品话术。
4. **现行规则优先。** 不学习历史稿中的短期表现、产品规模／份额／净流量、A股具体公司及无依据的收益暗示。旧费率、分红机制、交易机制或产品身份都不能自动复用。
5. **判断说明放对位置。** 来源核对与证据缺口留在对应区域；正文用准确范围表达结论，避免每段变成核验备忘录。影响判断的实质限制仍须保留。
