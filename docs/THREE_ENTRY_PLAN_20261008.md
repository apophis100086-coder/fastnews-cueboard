# 三入口与带教交付实施记录

2026-10-08。基线为改进实验版 `4708cea`，分支 `codex/three-entry-20261008`。原项目及 WorkBuddy 使用版保留。用户要求依次完成三入口、整体体验调优、搬运整合；目标 Windows 10/11 和 OpenAI 兼容 API。

## 1. 三入口

- WorkBuddy 与 Codex 共用本地绑定任务协议，人工在所选客户端说“处理看板任务”。不读取客户端凭据，不自动回退其他入口。
- API 设置独立存储，支持 Chat Completions 与 Responses；普通兼容接口不默认具备搜索工具。地址、模型、额度上限及材料外发许可显式配置，密钥不进入数据库、日志、备份和发行包。
- 统一连接检查、请求身份、停止、失败保存、入口标签；配置不等于已验证。
- 验证配置迁移、停止/重启、入口切换、秘密隔离、API 协议及错误处理。

## 2. 体验与存储

- 实际浏览器审查首次使用、晨报、检索、选材、写作、历史、导出、窄屏；优先减少迷路、无反馈和误操作。
- 数据管理提供 SQLite 一致性备份与可验证恢复；保留原库，恢复到新目录，不覆盖运行库。
- 核对人工选择、截点、证据链、失败隔离、写作模板及旧稿失效规则；执行相关及完整回归。

## 3. 迁移交付

- 源码检查通过并提交后构建带内置运行时的 Windows 包，默认空业务库。
- 带入已授权样例/模板，排除个人资料、账号、密钥、原业务库及运行记录。
- 新中文空格路径解压验哈希、启动、空库、三入口配置、任务协议、备份恢复、端口冲突及停止。
- 附给带教的首次使用指引、故障排查、验收与限制。未取得外部账号响应的入口只能标为接口验证通过，不能报告账户接通。

官方接口依据：https://learn.chatgpt.com/docs/build-skills；https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create；https://developers.openai.com/api/docs/guides/tools-web-search。
