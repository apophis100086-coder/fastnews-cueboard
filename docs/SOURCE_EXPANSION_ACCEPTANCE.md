## 结果与口径

当前原始 26 个来源登记保持不变，另以覆盖层增加 6 个同发布者的细分栏目，共 32 个采集入口。已配置 14 个元数据采集器，本次 13 个入口返回可解析的真实条目，FDA 仍连接失败。上一阶段是 6 个已适配、5 个读取成功。

**13 个入口分属 7 个发布者域名，不等于 13 家独立网站，更不表示原 26 个网站已经全部接通。** 读取成功只说明当前公开列表或数据接口可用，不保证完整历史、持续可用、全文权限或事实核验。一天没有新条目也不是采集失败。

## GitHub 参考与实施选择

- [RSSHub 的华尔街见闻路由](https://github.com/DIYgod/RSSHub/blob/master/lib/routes/wallstreetcn/news.ts) 展示了按网站编写专用适配的方式。现项目独立解析公开页面的结构化列表数据，不执行网页脚本、不调用付费接口，也不跟随该路由采集文章详情。
- [AKShare 沪深港通实现](https://github.com/akfamily/akshare/blob/main/akshare/stock_feature/stock_hsgt_em.py) 提供了东方财富公开数据接口和字段口径线索。再核对东方财富自身页面脚本后，独立实现方向 `006` 的南向统计，并保留原始字段、单位和获取时间。
- [港交所 RSS 监测项目](https://github.com/longbridge/hkex-rss-monitor) 与[港交所官方 RSS 说明](https://www.hkex.com.hk/Services/RSS-Feeds?sc_lang=en) 支持采用正式提供的订阅入口；没有将 RSS 的可用性扩展解释成其他网页的采集授权。
- [NLM 的 ClinicalTrials API 指引](https://www.nlm.nih.gov/pubs/techbull/ja25/ja25_clinical_trials_screen-scraping.html) 指向公开 API，但本机真实连接仍失败，未把文档存在写成已经接通。

没有引入 RSSHub 服务、AKShare 依赖或代理池，也没有复制其实现代码。网站需逐个核对入口、字段、日期和访问规则，通用爬虫不能代替这些工作。

## 代码改动

- `source_channels.py` / `config/source_channels.yaml`：追加同发布者栏目；禁止覆盖原来源 ID 或悄悄引入其他主机。覆盖层幂等，已保存的停用偏好继续生效。
- `source_parsers.py` / `live_sources.py`：新增公开数据 JSON、结构化公开列表和官方 RSS 解析。错误结构统一转为单源解析失败，其他来源继续。
- `source_catalog.py` / `product_discovery.py`：领域来源先于宽泛晨报进入固定来源请求预算；最多 8 次固定源/搜索预算继续生效。用户页面和站点查询使用东方财富阅读网址，内部采集使用已核对的数据端点。
- `network.py`：仅对东方财富数据主机已实测的精确 `/robots.txt`“请求 URL 格式异常”JSON 响应识别软 404，记录真实 HTTP 200；其他主机、HTML 验证页、403 和 robots 禁止规则不放行。TLS 证书、公开 IP、危险重定向和请求限额继续检查。
- `reading_reports.py`：统计期独立传给检索材料，首次公开时间未知时明确待补证，不以交易日冒充公开时间。
- `source_health.py`：未接适配器同时存在实测访问限制时显示“入口访问受限”，避免让用户误以为只差一个解析器。

## 尚未解决的入口与下一步路径

| 入口 | 已观察到的障碍 | 可行路径 |
|---|---|---|
| 证券时报 e 公司、第一财经、智通、港交所统计、披露易、SMM（6 项） | 已核查条款限制未经授权的自动访问或再利用 | 正式授权接口/订阅或有权使用的人工材料；不靠更换爬虫绕过 |
| SEMI、CDE | robots 请求 403 | 需公开允许的订阅/API 或访问规则变化后重验 |
| NMPA | HTTP 412 | 需可正常访问的公开接口或订阅；未通过验证，不强行采集 |
| 医药魔方 | TLS 证书验证失败 | 站点证书恢复或正式数据接口；不关闭证书校验 |
| FDA | TLS 握手失败，已有解析器 | 网络恢复后可在看板单源重试 |
| ClinicalTrials | 网页/API 真实连接均未完成，尚无已验收采集器 | 网络路径恢复后按官方 API 接入并验收 |
| 农业农村部、国务院政策库 | robots 禁止当前目标路径 | 寻找官方允许的订阅或接口，保留原站阅读 |
| UBS | 动态地区入口，尚无已核对的公开列表协议 | 定位公开数据出口并核对日期、许可；当前保留东方财富/财联社南向信息补充 |
| 中国半导体行业协会 | 当前公开外壳依赖额外脚本，相关 CDN 访问受限 | 核对可允许访问的新闻列表或官方订阅；现由 TrendForce 等补充，保留真实发布者 |
| 丁香园 Insight | 数据库需要登录，尚无已验收公开采集入口 | 取得正式数据权限后接入，或人工材料 |
| 农产品市场信息平台 | 发现的响应夹带文章全文，尚无已审核的元数据入口 | 寻找仅列表协议；本轮不扩大晨扫全文范围 |
| Mysteel | 商业再利用/部分内容权限仍需确认，未实现采集器 | 正式授权或核对范围明确的公开订阅 |

上述剩余 19 个入口并非全部为“网站难爬”，也不是全部已经解决。核心四产品已增加实际供给，但医药原始公告、上市公司公告、农业和金属仍有明显缺口。媒体线索补充不能替代缺失的原始证据。
