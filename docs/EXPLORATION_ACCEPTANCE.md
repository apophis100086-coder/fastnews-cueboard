# 产品双栏与继续探查验收｜2026-09-17

本轮把近期线索、持续适用背景和按需全网探查接入五只产品的共用流程。实现基于既有 Python、SQLite、单页看板；没有新增服务、向量库或数据库迁移。开发基线 `64cf5a3`，迭代分支 `codex/relevance-first-exploration`。

## 已交付行为

- 产品页桌面并排显示近期线索与产品背景，小屏上下排列；默认最多10条、5条，不凑数。短卡片展示摘要、产品关系、当前价值、公开日期、统计期及出处，判断和证据按需展开。
- 7天/120天是可配置的优先检索范围。较早的政策、经营、产业或资金背景可以进入判断；截点之后公开的材料仍排除。旧公告在本期进入新阶段，不因公告较早而强制标成背景。
- 公共判读、常规检索、继续探查提示词分别位于 `prompts/product_reading_common.md`、`product_reading_baseline.md`、`product_reading_explore.md`。输入记录提示词内容哈希、产品观察方向、来源边界、截点、已见事件与未解决问题。
- 五产品观察方向由 `config/product_reading.yaml` 覆盖层补充。科创50增加经营研发、商业化和指数结构；半导体设备增加订单与客户验证；恒生科技覆盖平台、AI云、应用、监管和资金；港股红利覆盖分红现金流、利率、行业和南向；创新药覆盖临床、审批、授权、支付和商业化。
- 跨期只复用符合目标截点的公共研究材料，要求模型重新说明当前有效性。人工备注、未公开稿件、私有持仓文件不会自动进入检索输入。
- “继续探查”不执行固定来源整轮采集，不设置固定网站白名单；尊重已停用域名及正文访问限制。可选补充需求最多500字，每轮最多5条增量，沿用原期次截点。
- 重复事件和已有证据会归并；新阶段、统计期与新增依据分别处理。结果追加，原条目位置保持，超过默认数量可展开。候选已有事件需明确点击合并，再保存新版本；旧决定和旧导出保持原内容。
- 默认折叠的辅助区域改名“已采集资料与原文核对”，分别说明产品匹配量和本地资料池总量。

## 任务、时限和并行操作

`POST /api/explore` 接收 `edition_id`、`reader_profile`、`research_question`、`request_id`，返回 `job_id`。`GET /api/job?id=…` 查询状态，`POST /api/job-stop` 提前停止。原常规研究接口保留。

任务接收时建立单调时钟截止时间，默认480秒；模型最多450秒，扣除准备耗时并预留至少30秒校验及清理。CLI内部重连不重置截止时间。Windows Job Object 负责退出时清理子进程；只有完整完成、结构与来源校验通过的结果才能保存。取消、超时、错误格式或执行失败不保存半份报告。

产品、期次、截点、来源配置和宿主设置固定到任务快照。报告输入中保存请求ID、任务ID及起止时间。重复请求不创建第二次调用，服务重启后仍可对应原任务；未完成报告标记中断。近期/背景/探查轮次采用现有报告表的JSON字段保存，旧报告兼容读取。

全局只允许一个重型任务；人工加入、移出、勾选、备注、保存、导出可同时进行。网络等待不持有写事务，保存仍检查决定版本。完成时仅刷新对应期次的结果区域，不重载编辑表单，不切换工作区或自动滚动，不把结果写入后来选中的产品。

每日12次宿主尝试、24,000字符资料输入、正文读取预算继续生效。24次搜索是给宿主的计划约束，实际次数由工具动作审计，超出会提示；内部模型请求和token无法由本地逐次控制。token只记录宿主实际返回值，未取得时为未知。

### 仍存在的覆盖与证据缺口

- CLI返回可观察的搜索/打开动作，但本次未返回可独立比对的页面全文。模型报告的片段仍标“宿主报告待复核”；搜索摘要继续标搜索摘要，未新增已核实Fact。
- SEMI国际站正文读取受限，部分材料仅取得公开索引；设备地区细分数据、存储投资预测后续修订仍有缺口。统计局及SEMI召回成功不表示这些站点全部接通。
- 缺少有日期的完整持仓及指数权重，产业或公司案例不能直接外推整个ETF经营表现。红利的利率、市场机制未完成全覆盖；创新药仍缺完整临床终点、正式支付名单及部分交易终止条款。
- 港股红利和创新药两轮使用已有公开报告做对照；它们有新材料，不代表连续每轮都会有增量。无新增和重复探查的行为另外通过离线测试验证。
- 五产品共用机制通过离线验收；本轮真实联网覆盖上述三产品，没有宣称对另外两只也重新进行了实网检索。WorkBuddy、Wind及独立搜索API仍未通过本轮接入验收。
