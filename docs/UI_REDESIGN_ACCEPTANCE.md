# 信息源使用方式与页面视觉改版验收

日期：2026-09-16。沿用原 Python、SQLite、YAML 和原生 HTML/JavaScript 页面，在现有实现上维护。未重建数据库，未更换前端框架。

## 信息源收口

按本轮用户要求，来源扩展停在现有范围：32 个启用入口中，13 个作为日常自动采集入口，19 个保留原站供手动查阅。13 个入口涉及 7 个发布者域名，不是 13 家独立网站。原 26 来源配置、追加栏目、个人启停和网址偏好均保留。

- 综合晨报采用财联社和华尔街见闻；港股及南向补充东方财富、财联社、港交所官方新闻 RSS；科技采用集邦、财联社、华尔街见闻、工信部、国家数据局；医药采用财联社创新药、华尔街见闻医药。
- 手动入口提供“打开查阅”和“补充到背景”。后者只在当前期次新增一条空白、未选用的人工补充，附来源名称及网址，不自动编写内容，不调用模型。
- 可对应的手动入口列出“同类资讯补充渠道”。媒体消息不能代替监管公告、交易所数据或专业数据库；农业、金属等没有合适的已接入对应栏目时不虚构替代关系。
- `source_usage.py` 是运行时使用方式覆盖层，不写来源偏好。普通按日采集、产品固定源补取、宿主定向查询只使用适用入口。手动参考列表留在页面，不送入宿主的查询计划。已有引用材料仍可作为明确标注的历史背景。
- FDA 保留原采集器和诊断能力，但因重复真实 TLS 失败暂列手动。明确的单源诊断仍可重试，不关闭证书校验。用户自建“链接”来源仍参加原有关键词检索，自建订阅仍按原有配置采集。

本轮通过隔离库页面“更新全部自动来源”进行了真实采集：2026-09-16 21:52 北京时间启动，13 个入口全部返回可解析列表，19 个手动入口未请求；新增 7 篇，28 次网络请求、0 次失败、0 LLM、0 搜索、0 全文请求，耗时 69.984 秒。13 个列表均继续标为 `partial`，原因是公开列表范围不完整；窗口无条目也不冒充采集故障。证据：`data/ui_redesign_20260916/live-scan.json`。本轮采集写入的是隔离验收副本，未向正式库灌入测试内容。

## 视觉与操作

参考用户两张海报的深蓝、红色强调、浅色纸感、分步信息层级和数字图形，使用 `marketing-visual-design` 技能检查中文排版。页面保留华泰柏瑞项目名称，未复制参考海报中的华夏标识、产品名称、比例或投资宣传数据。

| 页面 | 实际调整 |
|---|---|
| 全局 | 蓝红纸感视觉、统一中文字号与间距、三步导航、明确主按钮、折叠次要说明；保留现有表单、工作区切换及草稿 |
| 晨报速览 | 分类总报为主要阅读区；侧栏用真实报告条数显示分类分布，可点击筛选；没有报告时显示空状态；显示当日列表数、来源状态和当前候选数 |
| 产品检索 | 产品与日期操作集中；截点以易读北京时间显示，精确 ISO 字段保留在可选设置中；网站定向与关键词补漏分成两块，手动原站另作参考 |
| 选材与导出 | 候选池与快讯背景并排；背景区采用浅暖色纸面；保留多选、移除、恢复、排序、人工补充、保存与导出 |
| 信息源 | 自动入口与手动查阅分组；领域筛选包含晨报；来源比例图显示当前启用入口构成，不表示质量评分或无遗漏；旧诊断详情折叠保留 |

条形图采用原生 `progress` 属性和外部 CSS，不依赖会被 CSP 阻止的内联样式。未放宽原有安全策略。没有增加外部字体、图表依赖、图像追踪请求或模型调用。
