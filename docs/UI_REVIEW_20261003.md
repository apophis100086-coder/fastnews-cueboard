# 2026-10-03 全流程界面审查与改版

## 审查结论

当前三个业务入口可用，但常用操作、备用操作和说明混在一起。晨报同时出现列表采集、总报生成、日期快捷键和空分类侧栏；产品页的设置与启动分属不同卡片，存在多层重复标题；写作页首屏主要显示要求和材料按钮，当前稿件被推到下方。来源、连接、个人方案及运行记录常驻主流程。样式文件连续追加不同颜色、尺寸与布局规则，最终效果由覆盖顺序决定。

以实际历史数据观察：写作页3条已选材料保留；最新稿件已有21个预览段落，仍有较长来源及模板块。兼容单换行历史稿和人工修改是补充检查，不能把最新稿件描述为未分段。改版前截图保存在本地 data/acceptance/ui_20261003。

## 设计与实施计划

定位为带教使用的日常编辑工作台，保留华泰柏瑞品牌、三个入口、五个产品及人工选材权。采用本项目原生 HTML/CSS，统一浅色背景、红色主要操作、深色正文和中性辅助文字。design-taste-frontend 的审查方法用于复盘，其营销页、装饰动画和重建框架要求不适用于本产品流程。视觉变化程度4、动效1、信息密度4。

1. 每个页面集中一个主要操作。日期捷径、来源、设置、期次和运行记录收进明确命名的展开区域，不删除能力。
2. 晨报改为完整阅读区域；分类筛选只在有结果时出现，删除空侧栏占位。
3. 产品、可见截点与检索按钮放在同一操作区。历史期次、资料导入及继续补搜按需展开。
4. 写作以当前正文为中心，材料侧栏紧凑展示，写作要求收起；主新闻、必写和移除放到材料选项中。历史稿件库默认收起。
5. 整理正文标题、段落、出处与固定公司模板的展示；保留完整复制、Word、追溯、人工编辑与旧稿行为。选材变化时明确提示并禁用当前稿导出入口。
6. 用一份有分区、明确断点的视觉样式替换累积的覆盖层，检查桌面、窄屏、键盘、长文本、空结果和失败提示。
