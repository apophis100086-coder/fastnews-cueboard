# 实验版演示与真实验收

演示只在“快讯AI看板 改进实验版”进行，原 WorkBuddy 保持 8767。

1. 在 WorkBuddy 打开实验目录，启动一键启动.cmd，网页为 8787。看到“智能体直连”表示配置状态，不能据此宣布模型或联网已验证。
2. 晨报点击用户触发的 AI 总览，展示近两天主列表、近七日脉络、日期出处和领域缺口。未接通来源如实保留。
3. 选择产品，检查当前线索、背景与待补证；人工决定采用哪些材料，保存选择。
4. 点击生成，在 WorkBuddy 说“处理看板任务”。智能体依次完成补搜、起草、编辑兼核验及回写；页面继续执行程序检查。步骤待办不是整项任务终点。
5. 检查新闻正文、产品承接、来源、数字与待核对项。允许修改并保存新版本；人工选材改变后旧稿不能作为当前稿导出。没有自动发布。
6. 如需停止，在页面停止当前任务。已存中间稿保留，重启不会自动重放旧请求。

直连任务由用户手动停止，不再共用15分钟期限；容量和访问预算保持。不能承诺所有字句经程序事实验证，也不能称同一智能体的编辑兼核验为独立核验。

真正的质量验收用未用于调教的新题，三类各五篇。记录真实失败、程序待核对项、人工六项采用条件与编辑用时。历史试稿可解释界面，但不能计入新版本80%采用率，也不能提前宣布已达标。
