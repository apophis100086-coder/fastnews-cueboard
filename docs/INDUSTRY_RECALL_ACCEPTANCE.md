# 产业数据召回改进（2026-09-17）

## 问题与改动

科创50首份实际报告执行了8条查询，但把不同站点用OR组合，并把较长的问题和当天日期压入查询；国家统计局没有进入产品来源，SEMI中国未独立登记。已有公司的列表标题占据了推荐，72小时新闻窗口又过滤了较早发布的月度、季度产业数据。允许宿主联网并不等于这些方向已经检索完成。

本轮仍使用现有Codex订阅的实时搜索，没有新增API服务。变化如下：

- `research_sources.yaml` 追加国家统计局、SEMI中国两个公开研究入口。来源管理可停用；没有接通新程序采集器。34个登记入口中，自动采集仍为13个。英文SEMI的原有正文限制保留。
- 科创50（588090）与科创半导体设备（588710）先查生产、设备出货、晶圆厂/存储投资、硅片需求和行业会议五个方向，再查各站和产品关键词。每站独立短查询；补充词单独查询，不收窄所有必查方向。
- 每次宿主任务查询计划上限24条，预留4条换词补搜；关键方向缺失指标优先补查。不能用工业增加值、投资增速替代集成电路实物产量。临时打开失败时搜索完整标题、缺失指标和同站其他公开入口，不推造URL，不绕站点限制。
- 近72小时新闻与最长120天的指定来源统计/预测背景分开，背景最多3条，必须保留统计期与原发布时间。旧预测重述不刷新首次公开时间。新闻截点仍排除未来报道，未来实施和预测期单独保存。
- `search_audit.py` 按实际CLI搜索动作记录逐站和逐方向覆盖；独立查询、合并查询、未观察到查询分开。批量查询的简写摘要不重复计数，find词不计搜索。只查过不等于找到或读过原文。
- 卡片和MD/JSON保留背景身份、发布日期、首次公开和统计期。刷新不修改人工决定；加入候选与合并依据仍需用户点击。

宿主查询次数是提示词约束，运行后按可观察记录审计；目前CLI没有逐查询中断接口。超过计划会明确显示，不能声称严格拦截。内部token由宿主管理，本地继续限制输入长度、日任务次数和运行时间（480秒）。关键正文补读仍为3个事件、每事件2页，原二轮12事件/20全文/每事件4篇预算未改。晨扫仍为0 LLM、不抓全文。
