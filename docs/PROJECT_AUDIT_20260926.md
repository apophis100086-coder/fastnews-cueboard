## 已修复的可复现缺口

| 问题 | 改后行为 | 对应测试 |
|---|---|---|

| 标题只比较数字，可把正文中的20%变成标题20亿元 | 标题与正文均比较数值、单位和币种组合，标题仅从实际引用的陈述取依据。 | `test_title_cannot_change_an_observed_percentage_to_money` |
| “90%以上”可变成“超过90%”或精确90% | 在陈述、正文和标题三个位置核对常见百分比、货币及数量单位的约数、上下限；允许“不低于90%”与“90%以上”等同义写法。 | `test_quantity_bounds_checked_at_claim_body_and_title`、`test_writing_reader` |
| 旧版本标记“通过”后能绕过新增程序检查 | 每次导出用当前程序重新校验原始版本，不写回旧稿、不调用模型。复查可保存新的检查记录。 | `test_legacy_passed_draft_cannot_bypass_new_export_checks` |
| 页面预算触顶后，另条素材不能复用已取得的同一URL | 网络预算只约束新的读取；任务内已取得内容可继续共享，来源限制仍逐条执行。 | `test_shared_source_reused_after_page_budget_without_another_request` |
| 多个发布日期标签相互矛盾时，后标签覆盖前标签 | 冲突日期保留未知；同一天日期与带时区时间可采用更精确值；修改日期不当发布日期。 | `test_writing_reader` |
| 多页扫描PDF的页码标记被计入有效正文长度 | 先检查实际提取的文字，空页及页码标签不参与判断；无文字时明确要求补资料。 | `test_scanned_pdf_page_labels_cannot_count_as_extracted_text` |
