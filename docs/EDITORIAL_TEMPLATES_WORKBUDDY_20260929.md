# 公司模板、独立核验与 WorkBuddy 版

## 写作修正

基于 `d5d0bbb`，在 `codex/editorial-templates-workbuddy` 实施。正式 SQLite 已使用 backup API 备份至本地 `data/backups/editorial_templates_20260929/`，旧六篇输出和三份原配置记录哈希，不上传运行数据。

新的 `direct-newsroom-v3` 使用补充资料、起草、编辑、独立核验、模板组装。共用900秒：360/210/180/120/30。每一步返回后保存，核验失败保留编辑稿，编辑失败保留起草稿。人工选材、修改和历史框架均保持原记录。

起草与编辑只处理新闻正文及段落来源；核验合同没有标题或正文替换字段。旧 `direct-newsroom-v2` 和框架稿保留原契约。独立核验只处理新闻正文，公司固定文字来自冻结的模板版本。

公司模板位于本地 `data/writing_templates/library.json`，通过 `tools/import_company_templates.py` 从用户样例和明确提供的公开参考生成。版本、哈希、生效时间和准备时的文字变动随任务保存。模板原文、原始样例及实测稿件均不入Git。产品介绍、管理人介绍、产品备注、费率和风险提示统一渲染，红利系列风险提示只有一份。动态宣传数据无独立证据时不默认插入；费率和数据日期保留原资料日期。

- 科创半导体：https://www.jiemian.com/article/15126369.html

当前模板版本为 `company-copy-20260929-v1`。恒生科技取9月14日公司样例，红利取9月22日公司样例，科创半导体补充9月22日已发稿尾部。原样例中的费率漏字修复、移除可选旧数字均有准备记录，不是模型自由改写。

## 对照方式

`tools/run_template_acceptance.py --run` 在隔离副本回放原六篇，使用原第二次试稿保存的完整来源快照与选材，固定截点及 `gpt-6-sol/high`，关闭额外新闻补搜。新增公司模板作为明确的输入差异记录。原样保存起草、编辑、核验、成稿和失败状态，不将人工改写计入模型结果。

功能检查、来源核验与真实编辑采用分别记录。主线结构是否可保留、实际修改是否约10分钟内完成，由编辑反馈确认。

## WorkBuddy 交付边界

写作回放后建立独立 Windows 项目，默认8767端口，带入配置与样例，业务从空库开始。不会把原Codex正式数据库带入新项目。运行入口、登录、模型和联网分别验证；不使用开发会话凭证，不增加付费API，不静默回退Codex。

运行与打包的实测结果在实施后追加。本文件不把尚未完成的WorkBuddy认证或调用标为接通。
