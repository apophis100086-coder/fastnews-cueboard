## 第一项：三入口

已实现 WorkBuddy / OpenAI 兼容 API / Codex 三种执行选择，另保留“暂不使用模型”。客户端入口使用工作区、任务、步骤、请求摘要绑定的文件交换；有 claim、等待、停止和过期响应拦截。两套项目技能分别置于 .codebuddy/skills 与 .agents/skills，均通过技能格式检查。API 支持 Chat Completions 和 Responses，无静默重试或其他入口回退；Windows 用户加密保存密钥，迁移备份和发行包排除连接记录。

API 需使用者在页面填写服务商信息并明确授权任务材料发送与费用。默认单任务 4 次请求，每次 6000 输出 token，写作共用 900 秒。普通兼容接口只整理已有资料；只有明确支持 web_search 的 Responses 服务才启用该工具。工具轨迹不自动算已核实原文。
