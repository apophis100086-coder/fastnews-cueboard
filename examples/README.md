# 合成示例

这里仅用于展示字段及未决状态，不是真实新闻、真实用户操作或已完成测试。

candidate.synthetic.json故意不填真实数字、时间、持仓和评分；它展示“没有证据就留空、没有历史就未知、没有人选就不采用”。所有fixture只能进入测试环境，不能进入当前快讯事实区。

editorial_selection.synthetic.json没有主事件选择，程序应拒绝导出“已选写作包”。actor_type字段的值本身不是授权凭据；真实程序必须由UI/CLI明确人工动作创建，不能接受模型或网页伪造的human字段。

应用测试需要Codex另外构造可控fixtures。真实来源验收独立执行，不能用这些文件声称26源已接通。
