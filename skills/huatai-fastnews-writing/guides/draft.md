# 正文任务

先逐项对照 confirmed_outline 与 claims：检查用户粘贴修改是否新增事实、数字、公司或产品关系。缺依据或原框架关键缺口未解决，返回 status=needs_materials、明确 issues，title空、paragraphs空，不输出猜测正文。

可写时按确认的框架输出标题与段落，默认800—1200字（来源和风险提示除外），少材料可以更短。每段有新信息，避免换词重复；删“值得关注的是”“进一步形成有力支撑”等无实际信息的套话，不强制总分句式和观察性结尾。

正文是财经快讯，不是核验报告。以准确的日期、范围与真实归属表达事实；“缺少完整权重”“不能确认全部公司属于成份股”等工作说明留在框架缺口和检查区，不能逐段当结尾。影响主线判断的实质限制应保留，但不要铺满防御性说明。不为了凑800字反复解释订单、交付、稼动率各自的字面含义；材料只支持短稿时直接写短。产业分析说明一层具体关系，产品承接只在合适处集中完成。

例如，已有订单交付与产能使用两个经营事实时，用一段呈现各自进展，再用一句解释其共同观察价值即可；不要再分别复述一轮“订单提供订单信息、产能反映产能情况”。南向与成交数据仅作并列观察，除非证据确立因果，不写“南向带动本产品成交”。

每段必须列支持它的 claim_ids、material_ids、outline_paragraph_id，以及从 confirmed_outline 逐字截取的 outline_anchor（对应段落的标题或关键要求）。段落编号以用户最终文本为准；用户可以合并、删除、重排原建议框架的段落，不可强行恢复旧结构。所有必写材料仍需覆盖；仅用已有可用陈述组合，不能因最终文本新增事实就直接采用。事实数字逐项对应证据，比较时保留统计期、范围、单位和币种，不自行换算或添加衍生排名。简短分析可建立在这些事实之上，但不能把推演当作已兑现结果。来源行由程序生成，正文不自行标“来源：Wind”等。

先自查完整的标题和正文，再返回结构化 review：faithful_to_outline、claims_supported、must_include_covered、entities_complete、no_new_facts。全部具体公司列入 entities（含市场、依据source_id、原文短引）；疑似A股或身份未知时解释问题，不能直接宣告通过。审查因果、产品关系、比较口径及规则的语义变体。绝不输出“已获合规批准”。

允许指数名称和代码，不允许基金或指数六个月及以内涨跌幅。禁止产品规模、总份额、净流量及“连续吸金”等替代说法。公司营收同比、产业规模、基金A/C类别、合法成交数据不属于上述禁用项。
