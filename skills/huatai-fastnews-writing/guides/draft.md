# 成稿与轻量润色任务

先对照 confirmed_outline 与 claims。用户编辑框架新增事实仍需依据；主线关键缺口未解决时返回 status=needs_materials、具体 issues，title 与 paragraphs 为空。不得换主线或靠解释性文字凑篇幅。

可写时沿用户确认的主线和信息安排，写约1100字正文，段数随材料自然展开。标题和第一段突出主要变化，后续用独立事实与必要产品理解推进。analysis 或 product_connection 为空不必补一句。没有新信息的收尾直接删除；不要一路推演盈利估值，不独立讲指数机制。不输出核对备忘录、内部字段或“材料未提供”等工作说明。

篇幅指约1100个中文字符，不是1100个英文单词。围绕证实的具体事实写清对象、动作、细节和必要理解，材料充分时直接交付正文；不要额外要求更多独立事件个数、最新持仓、原始采访底稿或政策已经实施。真正需要补材料时，指出缺少的必要陈述及现有引文为何不能支撑，不把可省略的背景或同义重复当作阻断原因。

每段列 claim_ids、material_ids、outline_paragraph_id；outline_anchor 从 confirmed_outline 逐字截取对应要点。框架要点可合并或展开，自然段不必与原建议一一对应。必写项须覆盖，数字、范围、币种、期间和上下限对应实际引文，不自创换算、排名或因果。来源由程序逐段另列。

仅使用通过证据检查的陈述，不能自由联网或凭记忆补事实。产品正式名称与代码正常使用，但标题和正文禁止A/H上市公司名称及底层跟踪指数名称、代码；来源区保留真实出处。有依据和区间的连续增持趋势允许，精确规模、份额、净流量不可写。产品覆盖特点与本次主题直接有关，不引用旧季度报告来介绍当前产品。

同一任务内按 style 完成一次轻量润色，再返回模型原始成稿。review 检查 faithful_to_outline、claims_supported、must_include_covered、entities_complete、no_new_facts。editorial_review 逐项说明主要信息位置、独立事实增量、产品关系、重复机制、泛泛收尾、说明书式产品段；发现问题先在本次输出前修正，不能只匹配禁词。此为模型编辑检查，实际采用与10分钟修改目标由用户验收，不能声称可直接采用。实体识别覆盖全文，未知身份列 issues。

editorial_review 的 generic_endings 同时检查段中无新增信息的保留意见，product_manual_style 同时检查产品资料核验口吻；逐句判断是否带来新的事实或必要理解。若正文仍含这些问题，在 issues 指出具体原句，不可一边保留它一边自评“没有空泛表述”。
