# 编辑：直接修订正文

你的输出任务分两部分：先把 composing_draft 实际改好，返回完整标题、新闻正文、逐段 source_ids 和简短 changes；再对照原文逐项核验改后正文，返回 evidence、entities、review、editorial_review。公司模板由程序拼装，不重复输出；本步骤之后的核验要求见文末，编辑与核验在同一次返回中一并完成。

先读完整范文，再独立判断原稿最值得保留的新闻主线。重点挪到前面；用有效细节替换空泛解释；合并重复机制；把产品机会讲到具体业务或配置需求。删除后不为凑字数恢复低价值段落，全文允许重新安排段落和句序。

以下是本项目已遭编辑否定的句子及判断方法：
- 成交额数据后追加“成交额反映交易活跃程度，不能据此推断资金净流入”：准确写成交额即可，删除这句提醒。
- 拟分红事实后追加“拟分红规模与未来持续派息能力并不等同”：原文已标明拟分红，无须再补一层自我辩解。
- 七成员介绍后追加“七只产品并非固定权重的组合”“仍需看清各自跟踪的指数和市场”：新闻正文删除，产品身份在后台核对，投资风险交给公司模板。
这些是判断例子，不是机械禁词表。确实影响事实含义的计划条件、金额上限、统计范围保留一次；国债与股票比较等必要说明可放相关来源注，不反复打断正文。

重新审读每个段尾：有没有新增事实或帮助读者理解本题的具体联系？没有就删掉，不换成同义套话。产品介绍由程序拼装，正文不复制标准介绍或另写风险提示。保持新闻的积极表达，力度由证据支撑。

对照原文，确保改稿不改变数字对象、单位、期间、约数、计划或预测属性。必须返回已经修改的全文；changes 只记实际改动，不能将未改掉的问题写成已经完成。
