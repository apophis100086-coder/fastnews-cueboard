# 新闻写法与同轮轻量润色

事实准确、信息量、逻辑、产品关系优先于修辞。标题概括最值得注意的明确变化，自然带出产品，不堆新闻全称和全部数字。开头不一次塞完全文，也不先用抽象判断代替新闻。

段落随独立信息自然展开，不固定三段或五六段。每段首先确定“这里新增什么”，事实已能说明问题时，analysis 和 product_connection 可以为空。必要关系讲清即止；产品可较早出现，不机械留到结尾，也不只剩产品名和代码。不要重复“提供观察窗口”等空泛承接。

成稿后在同一次任务内做一次轻量润色：
1. 逐段确认新增事实或必要理解；没有增量、重复解释同一机制的段落合并或删去。
2. 看主要信息是否在前，主语与动作是否明确，长句能否拆开，过渡句是否增加信息。
3. 核对产品关系能否用1—2步说清；介绍围绕本次主题，避免机械清单和说明书。
4. 删除空泛对冲、泛泛总结与无事实支撑的力度词；准确保留计划、预测和实际影响的条件。
   检查整篇，不只看最后一句。已用“提出”“将”“预计”说明阶段后，不追加“具体实施情况仍以正式发布为准”；已按主题解释产品关系后，不追加“不能据此推断属于基金持仓”。这些是内部核验事项，直接不作相关推断即可。金额上限、里程碑触发条件、申请受理与批准的区别仍须在对应事实处准确表述。
   产品段直接说已核对的覆盖方向和相关特点，不写“某年某月更新的资料概要显示”，不用“提供产品关联”等工作用语。资料日期与出处只进入来源区。
5. 不换用户选题，不补造事实、数字、因果或公司身份。润色后再次核对引文与正文。

约1100字要靠补足有效材料，不能拉长分析。素材不足返回具体缺口，不能把明显短稿标成完整成稿。模型原稿原样保留供编辑验收，不用人工重写后的稿件冒充模型成绩。

参考本地 anti-defensive-writing 的方法：先分辨保留意见是否改变事实范围或读者理解；必要边界只在相关事实处准确写一次，其余删除。句子直接交代证据支持的对象、动作与范围，不以“我们不能证明什么”组织新闻段落。该方法不替代V6.4，也不放松来源、计划/事实和产品身份核验。
