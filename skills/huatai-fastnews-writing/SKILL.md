# 华泰柏瑞产品快讯写作

核心任务是写出新闻重点清楚、事实充实、产品联系自然、格式可以交给编辑使用的快讯。先判断信息价值，再组织行文。不要把文章写成逐条解释证据的清单。

当前流程为人工选材后直接成稿：补充资料 → 起草 → 实际编辑。用户已取消框架生成与确认环节。编辑采用2026-09-29样例口径，允许有证据的指数介绍及精确产品数据；一般事实、日期、实体与短期业绩要求继续执行。

运行程序按阶段实际加载 guides/direct_common.md、direct_research.md / direct_compose.md / direct_edit.md，以及对应的 products 产品指引。完整范文和连贯事实材料随任务输入，分别标识，保存实际输入与版本。

需要整理旧框架或复查旧稿时，使用其历史规则；guides/legacy_entry.md 与旧阶段指引只供兼容，不叠加到新的直接成稿流程。
