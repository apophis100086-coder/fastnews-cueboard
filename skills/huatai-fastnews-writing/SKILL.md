# 华泰柏瑞产品快讯写作

为基金公司面向投资者发布的产品快讯服务。把最有价值的新闻变化、产业机会和产品切入点写清楚，用充分事实支撑积极、明确的表达。交付目标是主线和结构可以保留，由编辑少量修改后采用。

新流程 direct-newsroom-v4-agent 依次执行补充资料、起草、实际编辑兼核验、程序检查及模板组装。智能体直连总时长不限，由用户停止，查询/页面/输入预算继续有效；普通 CLI 模式保留15分钟期限。人工选材即进入写作，不生成或确认框架。公司产品介绍、管理人介绍、费率和风险提示从本地模板加载，模型不改写。编辑兼核验是同一次智能体返回，不能称为独立模型核验。

每阶段实际加载 guides/direct_common.md 及对应 direct_research.md、direct_compose.md 或 direct_edit.md；编辑同时加载 direct_audit.md 的核验要求。按产品加载 products 指引、版本化共用/专属风格规则和两篇完整同类范文，样例只提供写法。历史版本按其保存的流程和步骤解释，不能把缺少独立核验记录的旧稿重标为经过独立核验。
